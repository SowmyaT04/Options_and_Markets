# Assignment 2 — Options Strategies and Market Analysis

## Task 1: Option Chain Data Collection and BSM Model Application
Downloads option chain data and selects at least 10 ITM, 10 OTM, and the most appropriate ATM options across two months. Uses the Black-Scholes-Merton (BSM) model to calculate fair values for each option, compares them to market price to flag overpriced/underpriced options, and identifies which calls are worth buying.

## Task 2: Stock Option Data and Monte Carlo Simulation
Downloads historical stock/option data for a chosen stock and runs a Monte Carlo simulation to generate possible future price paths. Plots the actual historical price series alongside the simulated paths for comparison.
